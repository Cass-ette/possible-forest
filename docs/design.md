# 可能森林 / Possible Forest — 设计文档

> 为执行功能障碍与 ADHD 倾向人群设计的弹性任务规划 App
> 苹果移动应用创新赛 · 2026.06.30 截止

---

## 一、产品定位

**一句话**：让每个任务选择都通向新的可能性——没有失败，只有转向。

**Slogan**：你的森林没有死胡同。

## 二、目标用户与人文关怀

- **核心人群**：执行功能障碍 (Executive Dysfunction) / ADHD 倾向成年人
- **核心痛点**：
  - 主流日历/任务工具假设用户能"启动 → 持续 → 完成"，但 ADHD 人群在"启动"就卡住
  - 卡住后产生羞耻感循环，进而彻底放弃工具
  - 传统"失败"机制（红色逾期、断签）会强化负面自我认知
- **科学依据**：
  - Cleveland Clinic: 执行功能障碍是神经性"can't"而非行为性"don't want to"
  - 北大心理学系: ADHD 执行功能缺损导致任务切换困难
  - Chunk App: 任务瘫痪会演变为逃避与羞耻循环
- **差异化**：把任务工具从"效率工具"重构为"无障碍辅助"

## 三、核心机制

### 1. 动态分支任务树 (Dynamic Branching Task Tree)

每个任务有 3 种结局，每种结局解锁不同后续：

```
        [复习考试]
       ╱    │    ╲
  完美    部分    放弃
   ↓      ↓      ↓
[看电影] [再刷题] [散步]
 奖励    补救    心态
```

- **不是静态 DAG**：拓扑随用户选择动态演化
- **没有"失败"**：放弃也是有效路径，导向不同支线
- **用户感知不到复杂度**：只看到"今天先做这个吧" + 3 按钮

### 2. 宠物性格演化

宠物观察用户选择模式，4 个维度性格动态变化：

- **勤奋** (diligence)：常完美完成 ↑
- **灵活** (flexibility)：常放弃/部分完成 ↑
- **耐心** (patience)：常部分完成 ↑
- **好奇** (curiosity)：常放弃（探索新路径）↑

性格影响：宠物动画、对话风格、解锁分支倾向。

## 四、视觉设计

- **风格**：iOS 26 Liquid Glass + 动森暖色 2D
- **字体**：SF Pro Rounded（iOS 自带）
- **配色**：
  - 背景：奶油黄 → 薄荷绿 → 樱花粉 渐变
  - 卡片：Liquid Glass（`.glassEffect(.regular)`）
  - 宠物：暖橙 + 奶白
- **动效**：弹簧动画 `spring(response: 0.4, dampingFraction: 0.7)`

## 五、交互极简化（苹果风）

用户全程只需 3 个操作：
- **点主按钮**：完成
- **点次按钮**：部分完成
- **点第三按钮**：改天吧

分支逻辑后台自动处理。用户**看不到拓扑图**，只感知宠物建议。

## 九、评委叙事

**开场**：每 5 个成年人中就有 1 个受执行功能障碍影响——他们不是懒，是大脑的"CEO"离线了。主流任务工具的红色逾期标记，正在把他们的羞耻感循环放大。

**核心演示**：任务"失败"不是终点。当你放弃"复习考试"时，宠物不会打叉，而是说"那我们去散步吧"——并且后续任务会因此改变，导向完全不同的支线。

**收尾**：可能森林不是效率工具，是**无障碍辅助工具**。它让每个选择都是有效的。
