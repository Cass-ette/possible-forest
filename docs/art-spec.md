# 🎨 可能森林 / Possible Forest — 美术资源 Spec
> 给画师/美术团队的需求文档

---

## 一、项目背景

- **产品**：可能森林（Possible Forest）—— 为执行功能障碍 / ADHD 倾向人群设计的弹性任务规划 iOS App
- **场景**：苹果移动应用创新赛（2026.06.30 截止）
- **风格**：iOS 26 Liquid Glass + 动森暖色 2D
- **核心要求**：**长期陪伴，宠物可无限成长**

---

## 二、整体视觉风格

### 参考方向
- **Finch Self Care**（最接近的参考，暖色 + 圆润宠物）
- **Animal Crossing**（动森：柔和渐变 + 治愈感）
- **Pusheen / Hello Kitty**（圆润线条 + 简单表情）
- **Genshin Impact 小道具**（高质感 2D 插画）

### 色调
- 背景：奶油黄 `#FFE8B0` → 薄荷绿 `#C4E9C9` → 樱花粉 `#FFC9D9`
- 宠物主体：**暖橙 `#FF9E6B` + 奶白 `#FFD3A8`**
- 强调色：**嫩绿 `#7BC97F`**（叶子）/ **柔粉 `#FFC9D9`**（花）

### 线条
- **圆润**，无锐角
- 描边 2-3px，柔和深棕 `#3A2B22`
- 内阴影柔和，高光偏白

## 三、🎯 核心需求：无限成长系统

### 3.1 成长结构

| 阶段 | XP 范围 | 标签 | 含义 |
|---|---|---|---|
| **种子** | 0-29 | seed | 初始形态，蛋形 |
| **幼苗** | 30-79 | sprout | 发芽，有小叶子 |
| **少年** | 80-159 | young | 完整身体，更多叶 |
| **成年** | 160-209 | adult | 开花，成熟形态 |
| **成年 Lv.2** | 210-259 | adult_lv2 | 花更盛 |
| **成年 Lv.3** | 260-309 | adult_lv3 | 多一种花色 |
| ... | ... | ... | 每 50 XP 升 1 级，**无限** |
| **成年 Lv.10+** | 660+ | adult_lv10 | 触发季节变体（见 3.3） |

### 3.2 设计原则（让无限成长可视觉化）

**模块化叠加**，而不是每级单独画一张：
- **身体基底**（4 个：种子 / 幼苗 / 少年 / 成年）
- **装饰图层**（可叠加：叶子 / 花 / 光晕 / 粒子）
- 等级越高，装饰越多

```
[基底]              [基底] + [叶]       [基底] + [叶] + [花]    [基底] + [叶] + [花] + [光晕]
种子                幼苗                 少年                    成年 Lv.1
                          
[+花瓣雨]           [+星星粒子]          [+彩虹环]
成年 Lv.5           成年 Lv.10          成年 Lv.20
```

### 3.3 季节变体（Lv.10+ 解锁，每 10 级一季）

突破单纯叠装饰的视觉疲劳，每 10 级解锁一个**季节形态**：

| 等级 | 季节 | 主色 | 元素 |
|---|---|---|---|
| Lv.10 | 🌸 春 | 樱花粉 | 樱花花瓣飘落 |
| Lv.20 | ☀️ 夏 | 翠绿 | 阳光斑驳、向日葵 |
| Lv.30 | 🍂 秋 | 琥珀金 | 枫叶、麦穗 |
| Lv.40 | ❄️ 冬 | 雪白 | 雪花、冰晶光环 |
| Lv.50 | ✨ 花期全开 | 七彩 | 所有季节混合 |
| Lv.60+ | 🌌 星灵 | 银河紫 | 星辰、极光 |

## 四、📦 资源清单（MVP 优先）

### 🎯 **MVP（8 天 demo 用）**：必交

#### 1. 4 个基础身体（每张含 4 种表情）

| 表情 | 用途 |
|---|---|
| neutral 默认 | 待机 |
| happy 开心 | 完成任务 |
| sleepy 困倦 | 改天 / 放弃 |
| thoughtful 想事 | 部分完成 |

**规格**：PNG 透明背景，@3x（≤1024×1024）

**4 身体 × 4 表情 = 16 张**

| 文件名 | 描述 |
|---|---|
| `pet_seed_neutral.png` | 种子形态 - 默认 |
| `pet_seed_happy.png` | 种子形态 - 开心 |
| `pet_seed_sleepy.png` | 种子形态 - 困倦 |
| `pet_seed_thoughtful.png` | 种子形态 - 想事 |
| `pet_sprout_*.png` | 幼苗 × 4 表情 |
| `pet_young_*.png` | 少年 × 4 表情 |
| `pet_adult_*.png` | 成年 × 4 表情 |

#### 2. App 图标
- **1024×1024 PNG**（无圆角，iOS 自动裁剪）
- 主体：宠物头像 / 抽象 Logo
- 风格：跟整体一致

#### 3. 首次启动插画 × 2
- 欢迎页：宠物种子刚冒芽
- "进入森林"页：宠物背对镜头看向森林

---

### 🌟 **Full 版**（赛后升级用）：可选

#### 4. 季节形态（6 个 × 4 表情 = 24 张）
- 春/夏/秋/冬/花期/星灵 各 4 表情

#### 5. 装饰图层（透明背景，用于程序叠加）
- `deco_leaf_01.png ~ 05.png`（5 种叶子）
- `deco_flower_01.png ~ 05.png`（5 种花）
- `deco_aura_ring.png`（光环）
- `deco_particle_*.png`（粒子）

#### 6. 海报素材
- 用于比赛海报背景
- 横版 + 竖版各 1

## 八、📝 给画师的对齐话术

> "做一个 iOS App 的宠物角色，陪伴用户长期成长。角色是森林里的小精灵，圆润治愈风，参考 Finch / 动森。
> 
> 需要 4 个成长阶段：种子（蛋形）→ 幼苗（带叶）→ 少年（完整身体）→ 成年（带花）。
> 每个阶段需要 4 种表情：默认、开心、困倦、想事。
> 
> 重点是**长期陪伴感**——角色要可爱到让人愿意天天打开 App。色调要暖（奶油黄、薄荷绿、樱花粉），线条要圆润，整体风格柔和治愈。
> 
> 后期还要做季节变体（春樱、夏阳、秋枫、冬雪），希望画风能扩展。"
